# cinex-Project
Project Description

The Smart Theatre Management and Ticket Booking System is a Java-based application that allows users to book movie tickets online. Users can select movies, show timings, preferred seats or rows, apply discount coupons, and order food for delivery to their seats at a selected time. After successful booking, the system generates a unique ticket ID and QR code for easy verification. An admin panel manages movies, theatres, seats, shows, coupons, food orders, and bookings.
